### インストール方法

1. **Tampermonkey をインストールする**  
   - Chrome : [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey-%E3%83%99%E3%83%BC%E3%82%BF%E7%89%88/gcalenpjmijncebpfijmoaglllgpjagf)
   - Firefox : [Tampermonkey](https://addons.mozilla.org/ja/firefox/addon/tampermonkey/)

2. **ユーザースクリプトを許可する**  
   拡張機能の管理で「ユーザースクリプトを許可」してください。詳しくは公式 FAQ を参照してください。  
   https://www.tampermonkey.net/faq.php?locale=ja&q=Q209

3. **日本語化プラグイン をインストールする**  
   次のリンクを開いてインストールしてください。  
   [ここからインストールする](https://github.com/grmpnk/github-japanese-localize/raw/refs/heads/main/userscript.user.js)

4. **インストール後の確認**   
   GitHub を開いて日本語化が適用されているか確認します。適用されない場合はブラウザをリロードしてください。
